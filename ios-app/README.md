# iPhone / iPad app

A Capacitor shell that opens https://vividenginesolutions.com full-screen, so every website
deploy updates the app. The Xcode project is **generated by CI** (`npx cap add ios`) and is
not committed.

Build and upload: GitHub -> Actions -> **iOS build (TestFlight)** -> Run workflow.
Setup steps and the three secrets it needs: see `docs/APP-LAUNCH.md` section 4.
